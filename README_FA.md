# Beni Live Call Captions — نسخه آزمایشی

این برنامه زیرنویس شناور انگلیسی به فارسی یا فارسی به انگلیسی نمایش می‌دهد.

## نصب فقط با گوشی
در GitHub قسمت Actions را باز کنید، اجرای Build Beni Android APK را انتخاب کنید و اگر سبز شد، از قسمت Artifacts فایل Beni-LiveCallCaptions-debug-APK را دانلود کنید. ZIP را باز کنید و app-debug.apk را نصب کنید. ممکن است گوشی برای نصب از مرورگر اجازه بخواهد.

## محدودیت
به‌دلیل محدودیت‌های اندروید، اپ به صدای هر دو طرف تماس عادی سیم‌کارت دسترسی تضمین‌شده ندارد. در حالت بلندگو ممکن است میکروفون هم توسط اپ دوم قابل استفاده نباشد. برنامه در نسخه فعلی صرفاً آزمایشی است.

## شروع
برنامه را باز کنید، زبان را انتخاب کنید، اجازه میکروفون و نمایش روی برنامه‌ها را فعال کنید، روی Start captions بزنید. برای تماس دکمه Open SIM dialer را بزنید.

## حریم خصوصی
متن در برنامه ذخیره نمی‌شود. سرویس تشخیص صدای نصب‌شده روی گوشی ممکن است پردازش صوت را از طریق ارائه‌دهنده خودش انجام دهد. از رضایت طرف تماس مطمئن شوید.
